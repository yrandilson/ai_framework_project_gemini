# Manual do AI Framework Core

Este manual fornece uma visão geral completa do **AI Framework Core**, incluindo sua arquitetura, componentes, instruções de configuração e um guia para o desenvolvimento de produtos.

## 1. Introdução

O AI Framework Core é uma plataforma modular e escalável projetada para acelerar o desenvolvimento de soluções baseadas em inteligência artificial. Ele oferece um conjunto de ferramentas e módulos reutilizáveis para construir bots, aplicativos, sistemas e automações com IA de forma eficiente.

## 2. Arquitetura do Framework

O framework é estruturado em módulos independentes que se comunicam através de um backend centralizado. A arquitetura visa a flexibilidade e a capacidade de extensão.

import os
from flask import Flask, jsonify, request
from flask_cors import CORS

# Adicionar o diretório raiz ao path para importar o core
import sys
sys.path.append(os.path.abspath(os.path.join(os.path.dirname(__file__), '..')))

from core.ai_engine.engine import AIEngine
from core.automation_module.automation import AutomationModule
from backend.config import Config

app = Flask(__name__)
app.config.from_object(Config)
CORS(app) # Habilitar CORS para o frontend

# Inicializar os módulos do framework
ai_engine = AIEngine(api_key=app.config['OPENAI_API_KEY'])
automation = AutomationModule()

@app.route('/')
def index():
    return jsonify({
        "status": "online",
        "framework": "AI Framework Core",
        "version": "1.0.0"
    })

@app.route('/api/chat', methods=['POST'])
def chat():
    """
    Endpoint para interagir com o motor de IA.
    """
    data = request.get_json()
    prompt = data.get('prompt')
    if not prompt:
        return jsonify({"error": "Prompt não fornecido"}), 400

    response = ai_engine.generate_response(prompt)
    return jsonify({"response": response})

@app.route('/api/automate', methods=['POST'])
def automate():
    """
    Endpoint para executar uma automação.
    """
    data = request.get_json()
    rule_name = data.get('rule_name')
    rule_data = data.get('data')

    if not rule_name:
        return jsonify({"error": "Nome da regra não fornecido"}), 400

    result = automation.execute_rule(rule_name, rule_data)
    return jsonify(result)

if __name__ == '__main__':
    app.run(host=app.config['HOST'], port=app.config['PORT'], debug=app.config['DEBUG'])
```

## 3. Configuração do Ambiente

Para configurar e executar o AI Framework Core, siga os passos abaixo:

### 3.1. Pré-requisitos

*   Python 3.8+ instalado.
*   Uma chave de API OpenAI (para o `AIEngine`).

### 3.2. Instalação das Dependências

Navegue até o diretório raiz do projeto (`ai_framework_project`) e instale as dependências usando `pip`:

```bash
pip install -r requirements.txt
```

### 3.3. Configuração das Variáveis de Ambiente

Crie um arquivo `.env` na raiz do diretório `backend` com as seguintes variáveis:

```ini
OPENAI_API_KEY="sua_chave_api_openai_aqui"
SECRET_KEY="uma_chave_secreta_forte_aqui"
DEBUG=True
```

Substitua `
sua_chave_api_openai_aqui` pela sua chave de API real da OpenAI e `uma_chave_secreta_forte_aqui` por uma chave secreta forte e única.

### 3.4. Executando o Backend

Para iniciar o servidor Flask do backend, navegue até o diretório `backend` e execute:

```bash
cd backend
python app.py
```

O servidor estará disponível em `http://localhost:5000` (ou na porta configurada).

## 4. Módulos do Core

### 4.1. Motor de IA (`core/ai_engine/engine.py`)

O `AIEngine` é a interface principal para interagir com modelos de linguagem. Ele abstrai a complexidade da comunicação com a API da OpenAI.

**Funcionalidades:**

*   `generate_response(prompt, system_prompt)`: Gera uma resposta textual com base em um prompt.
*   `analyze_data(data, instruction)`: Analisa dados fornecidos seguindo uma instrução.
*   `make_decision(context, options)`: Ajuda na tomada de decisões com base em contexto e opções.

**Exemplo de Uso (no backend):**

```python
from core.ai_engine.engine import AIEngine

ai_engine = AIEngine(api_key="SUA_CHAVE_OPENAI")
response = ai_engine.generate_response("Qual a capital da França?")
print(response)
```

### 4.2. Módulo de Automação (`core/automation_module/automation.py`)

O `AutomationModule` gerencia ações programáticas e a execução de regras de negócio.

**Funcionalidades:**

*   `send_message(recipient, message, channel)`: Simula o envio de mensagens para diferentes canais.
*   `call_external_api(url, method, headers, data)`: Facilita chamadas a APIs externas.
*   `execute_rule(rule_name, data)`: Permite a execução de regras de automação pré-definidas.
*   `save_data(collection, data)`: Simula o salvamento de dados em um banco de dados.

**Exemplo de Uso (no backend):**

```python
from core.automation_module.automation import AutomationModule

automation = AutomationModule()
result = automation.execute_rule("save_customer", {"name": "João", "email": "joao@example.com"})
print(result)
```

### 4.3. Utilitários (`core/utils/helpers.py`)

Contém funções auxiliares que podem ser usadas em todo o framework.

**Funcionalidades:**

*   `generate_id()`: Gera um ID único (UUID).
*   `get_timestamp()`: Retorna o timestamp atual formatado.
*   `load_config(path)`: Carrega um arquivo de configuração JSON.
*   `format_currency(value, currency)`: Formata um valor como moeda.
*   `validate_email(email)`: Valida um endereço de e-mail.

## 5. Backend (Flask)

O diretório `backend/` contém a aplicação Flask que atua como o cérebro central do framework, orquestrando as interações entre os módulos do core e as integrações.

### 5.1. `app.py`

É o ponto de entrada da aplicação Flask. Ele inicializa os módulos `AIEngine` e `AutomationModule` e define as rotas da API.

**Rotas Principais:**

*   `/`: Retorna o status do serviço.
*   `/api/chat` (POST): Recebe um prompt e retorna uma resposta gerada pelo `AIEngine`.
*   `/api/automate` (POST): Recebe um nome de regra e dados, e executa a automação correspondente via `AutomationModule`.

### 5.2. `config.py`

Define as configurações da aplicação, como chaves secretas, chaves de API e configurações de banco de dados.

## 7. Como Estender o Framework

O design modular do AI Framework Core facilita a adição de novas funcionalidades e a criação de novos produtos.

### 7.1. Adicionando Novas Integrações

Para adicionar uma nova integração (ex: Telegram, Slack):

1.  Crie um novo diretório em `integrations/` (ex: `integrations/telegram/`).
2.  Desenvolva a lógica específica da integração dentro deste diretório.
3.  Incorpore a nova integração no `AutomationModule` ou crie um novo serviço no `backend/services/` para gerenciá-la.

### 7.2. Criando Novos Produtos

Para criar um novo produto (ex: um bot para WhatsApp, um sistema de vendas):

1.  Crie um novo diretório em `products/` (ex: `products/whatsapp_bot/`).
2.  Desenvolva a interface do usuário (frontend) e a lógica específica do produto.
3.  Utilize o backend Flask e os módulos do core (`AIEngine`, `AutomationModule`) para as funcionalidades de IA e automação.

## 8. Considerações Finais

Este framework é um ponto de partida robusto para o desenvolvimento de soluções com IA. A modularidade e a reutilização de código são pilares que permitirão escalar seu negócio e criar múltiplos produtos a partir de uma base sólida.
